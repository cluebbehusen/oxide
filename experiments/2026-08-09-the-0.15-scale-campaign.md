# The 0.15 scale campaign (2026-08-09)

> Part of [the experiment log](README.md).

The 0.15 target is a class of match the engine has never carried:
grand maps toward the 256x256 legal edge, up to twelve seats, FFA
(which defeats the team-vision dedup by construction), and a tech
tree whose armies will dwarf today's. This file records the
performance work that has to land before that content is honest to
build, phase by phase. The campaign's hard rule: **a hash-neutral
phase moves zero state hashes** — every bench prints its final state
hash and every change is accepted only when those hashes are
bit-identical to the baseline.

Provenance: branch `0.15.0` from ce51073 (the 0.14.0 merge),
workspace 0.14.0 during this hash-neutral phase, release build, macOS
arm64 (the recorded machine), shipped ladder artifact.

Profile attribution at 256x256/8 seats (12 s `sample`): vision
refresh 31.6% self-time, fog-honest observation 12.4%, orientation
clone 6.2%, A*/Dijkstra heap 5.6%, memset 5.4%, defense-route

external probe at the 0.14 head: **692 ms** (bot planning burst,
53 ms even on shipped compass-grand). Every A* query memset 12
bytes/cell across the whole map before searching; the bot's mask
rebuilt the same passability grids and builder-route Dijkstra three
times per think; `tile_open` scanned map-sized vectors linearly per
placement candidate.

## Phase: A* generation stamps + per-thread scratch (cd0cd95)

Cells validity-stamped per query; the plain `astar()` entry borrows a
per-thread scratch. Query cost becomes proportional to cells touched,
not map area. All bench hashes bit-identical; means barely move (the
fill cost concentrates in query-heavy bot ticks, not steady state) —
this is the enabling fix the later phases stand on, and the one that
makes pit-detour geometry affordable at all.

## Phase: fog reconciliation bounded to stamped spans (a1bcda2)

The remembered-scrap/wreck freeze-frame walked every map row per team
per tick; nothing outside the row spans the sight stamps touched can
have become visible, so the walk now visits only those spans (the
per-cell visibility check still decides — coverage only bounds).

| Bench | before | after |
|---|---|---|
| synth 256x256, 8 seats | 1,192 | **1,477** |
| synth 256x256 rocky | 1,190 | **1,463** |
| synth 256x256, 2 seats | 2,428 | 2,699 |
| synth 106x64, 8 seats | 6,472 | 7,242 |

Hashes bit-identical across the suite.

## Phase: shared defense probes + indexed tile lookups (786d6f8)

One think now builds the KnownPassability grids and builder-route
Dijkstra at most once, shared across the Turret/Flak/Bastion mask
checks; `tile_open`/`rock_at` become binary point lookups on the
already-sorted known-tile vectors (the quadratic-in-area term on
rocky maps). Compass-grand 5,501 -> 5,882 in the same run conditions;
hashes bit-identical.

## Phase: windowed sidearms + the spike instrument (b541f02)

`fire_sidearms` scanned every unit in the world per off-cooldown
sidearm; the pick is keyed (distance, id), so it now walks the
spatial index's reach window — the acquire_target bound — with a
400-tick two-army differential test comparing every pick against the
verbatim linear chain. Interleaved A/B (three rounds each way) shows
equal-or-better today; the point is the O(n·window) scaling as 0.15
armies grow.

`driver bench` now prints per-tick latency digests (mean/p50/p99/max
with the worst tick's index, bot phase split out) — the spike is a
first-class measurement from here on. Current worst ticks, 6,000-tick
runs: compass-grand 58 ms, synth 256x256 322 ms, rocky 266 ms —
roughly half the pre-campaign probe's 692/643 ms on the same shapes,
with the remainder dominated by all Expert seats thinking on the same
tick (no per-seat cadence phase offset — a hash-moving fix scheduled
with the 0.15 retrain).

A methodology lesson recorded for every later phase: single runs
straight after a long compile read 10-25% slow (thermal); all
accept/reject calls here now come from interleaved A/B rounds.

## Phase: shell minimap texture + entity frustum culls (410cb89)

Presentation only, no sim cost: the minimap's per-tile
`draw_rectangle` loop (65,536 immediate-mode quads per frame at the
legal map edge) becomes one pixel write per tile into a cached
texture drawn as a single quad; unit and building draw passes gain
camera-rect culls. Full shell suite and the 14-check live smoke pass;
verified by eye on Continental Divide.

## Where the phase ends

Whole-workspace gates green (fmt, clippy -D warnings, 63 test
binaries, doc -D warnings) and `driver/tests/hashes.rs` confirms all
25 shipped fixtures byte-identical at sim_version 0.14.0 — the
hash-neutral claim, proven.

Deliberately deferred to their hash-moving windows:

- Vision storage layout (bitsets, sparse salvage memory, team-owned
  views) — serialized shape, rides the 0.15.0 version bump.
- Per-seat bot cadence phase offsets — decision timing, rides the
  retrain.
- Orientation's full-observation clone and fog-honest observation
  restructuring — bot-internal but measured against training
  throughput, lands with gym v9.
- Multi-goal A* for the approach/escape/chase fan-outs — changes
  which goal wins ties, rides the 0.15.0 bump.
