# UI typography

Chakra Petch Medium is the interface typeface, embedded for both body text and
short labels. The unmodified font is by the Chakra Petch Project Authors and
comes from the
[Google Fonts distribution](https://github.com/google/fonts/tree/main/ofl/chakrapetch).

Its SIL Open Font License permits personal and commercial use and redistribution
with the game. Keep the included copyright and license notice in `OFL.txt` with
the font.
